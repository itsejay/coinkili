# CoinKili 🇹🇿

Live cryptocurrency prices in USD and Tanzanian Shillings (TZS).

Made for Tanzania—track the market in local currency!

- Top 100 coins
- 24h change, market cap, volume
- 7-day sparkline charts
- Toggle USD/TZS

Built by a Tanzanian IT student to make crypto accessible locally.

Visit: https://itsejay.github.io/coinkili
